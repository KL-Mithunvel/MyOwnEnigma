# ARTY_S7 — board reference files

Digilent Arty S7 documents used by this project:

| File | What it is |
|------|------------|
| `arty_s7_sch-rev_e.pdf` | Board schematic (rev E.1) — source for the pin map in `../docs/HARDWARE.md` |
| `Mechanical_Arty_S7.pdf` | Mechanical drawing (board outline, mounting holes) |
| `Arty_S7.stp`, `Arty_S7_DXF.DXF` | 3D model / outline used to design the case in `../cad/arty-s7-case/` |

The constraints file is `../Arty-S7-50-Master.xdc` (Digilent master) and the project-specific
`../constraints/arty_s7_enigma.xdc`.
