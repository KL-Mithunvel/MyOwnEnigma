# Hardware photos

Photos of the built keyboard, lampboard, Arty S7 board and cases, renamed from the original phone exports
(`NN-subject.jpeg`, in the order they were taken). `tools/build_showcase.py` embeds six of them in the
showcase page (`HARDWARE_PHOTOS`). `24-paper-enigma-reference-sheet.jpeg` is a paper Enigma sheet by a third
party and is kept for reference only, not published on the page.
