# schematic — KiCad projects

| Project | Purpose |
|---------|---------|
| `schematicofkeyboard_101` | Keyboard: 29 switches + diodes in a 9x4 matrix, read through a CD74HC4067 16-channel mux |
| `lamproj` / `schematicsstest!` | Lamp board: 26 LEDs on two CD74HC4067 muxes (5-bit code + inverted MSB enable) |
| `sevens_segmentdisplayschem` | Seven-segment display experiment (not used by the current design) |

`schematicofkeyboard_101.zip` is the original archive (kept for history); its contents are extracted alongside.
Open the `.kicad_pro` files with KiCad 8. Signal names and pins are summarised in `../docs/HARDWARE.md`.
